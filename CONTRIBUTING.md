# Contribuer

1. Créer une branche courte.
2. Ne jamais ajouter de secret, de donnée personnelle ou de donnée projet réelle
   aux tests.
3. Ajouter ou adapter les tests pour toute règle de cohérence.
4. Exécuter `python -m compileall src` puis `pytest`.
5. Expliquer les effets sur le modèle de projet et sur les données transmises à
   l'IA.

Une modification de prompt ne vaut pas décision pédagogique. Les règles stables
doivent être codées dans les contrôles déterministes ou documentées dans le
modèle de projet.
